# 🚀 My Dotfiles

Personal configuration files for my CachyOS development environment.

![Terminal Setup](./terminal.png "My terminal configuration")

## Setup

- **Desktop:** Niri with Noctalia Shell.
- **Shell:** Zsh with Oh My Zsh, Atuin and Starship.
- **Terminal:** Ghostty.
- **Editors:** Zed and VS Code.
- **Agent tooling:** Oh My Pi and Herdr.
- **System information:** Fastfetch with a custom ASCII logo.

## Directories

| Directory | Local destination |
| --- | --- |
| `fastfetch/` | `~/.config/fastfetch/` |
